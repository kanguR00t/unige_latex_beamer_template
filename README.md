# UniGe DPNC LaTeX Beamer Poster Template

Just a small template for making posters using the approved UniGe colours (feel free to change to sciences colours in the colour theme if you like) and logos. With courtesy to Theresa Reisch, on whose template this is largely based.

## Compile

Simply clone this repo and run the following:

```bash
lualatex poster
```

Alternatively, feel free to import everything to OverLeaf and continue editing there!
